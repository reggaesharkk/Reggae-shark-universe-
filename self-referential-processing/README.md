## Phase 7 final status

The final locked Phase 7 aggregation contains **4,000 GLMM fits** across 500 deterministic replicates, four data-generating cells, and two candidate mixed-effects architectures.

Under the prespecified Phase 7 decision rule:
- M1 passed the tested null Type-I and confidence-interval coverage compatibility screens under both tested rho conditions.
- M2 did not pass those same null-calibration screens.
- M1 is therefore retained as the candidate architecture for a **future prospectively preregistered** confirmatory design.

This is simulation-based methodological validation. It is **not** live confirmatory evidence that a self-referential processing effect exists.

## Boundary with frozen v8.6.3

The original frozen v8.6.3 Gate 5 estimator remains the item-level linear probability model with two-way cluster-robust inference. The later M1 GLMM was developed separately in the Design Lab and is not retroactively substituted into the frozen protocol.
