**Prince Upadhyay, Independent Research — 25 September 2026**

The radial shell audit identified shell 7 as the strongest isolated old-core block and shells 7+4 as a 314-pair subset recovering about 5.11% quotient gain.

This gate asks whether those 314 corrections can be compressed further using simple structured mode classes.

Three taxonomies are tested independently:

1. sorted absolute-coordinate orbit
   [
   operatorname{sort}(|k_1|,|k_2|,|k_3|);
   ]
2. coordinate-wise parity pattern
   [
   (|k_1|,|k_2|,|k_3|)mod2;
   ]
3. coordinate sign/octant pattern.

For each taxonomy, every class is applied alone, ranked by endpoint log-C gain, and then accumulated.

The target is a small class family that recovers most of the shell-7/4 gain with far fewer than 314 phase pairs.
