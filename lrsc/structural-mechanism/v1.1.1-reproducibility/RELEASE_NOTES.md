# Release notes — LRSC v1.1.1

Separate reproducibility supplement for the fixed M=99, k_idx=49, theta=0.08, A=0.50 single-step benchmark. Includes PDF, Python source, C++17 enumerator, and recorded verification output.

Every subset at exact cardinalities K=1,...,10 is enumerated. The K=11 passing witness is directly reconstructed. This supports K_0.001=11 in IEEE double precision for the stated benchmark; it is not an interval-arithmetic or exact-rational proof.

Historical v1.1, frozen v1.2, and DOI 10.17605/OSF.IO/NM5BW are unchanged.
