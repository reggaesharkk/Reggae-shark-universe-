# LRSC Odd-Ring Spectral Rank Theorem
## Version 1.2 - analytic family result

**Author:** Prince Upadhyay  
**Affiliation:** Independent Research  
**Status:** Author theorem release  
**Scope:** Single-step near-Nyquist LRSC spectral operator on odd cyclic lattices.

## 1. Statement

Let `M >= 9` be odd and set `k=(M-1)/2`. On the cyclic lattice `Z_M`, define

`X_t = 1 + A cos(2*pi*k*t/M)`, with `A>0`,

and the local shedding field

`j_t = X_t - min(X_{t-1}, X_t, X_{t+1})`.

Let `m_t` be any reflection-symmetric binary mask, `m_t=m_{-t}`, with at least one inactive reflection orbit. Let `p` be the number of active reflection orbits. Form the conjugate-balanced pre-stencil channel family generated by the Fourier coefficients of `j`, and then apply the circulant stencil whose Fourier multiplier is

`s_q = cos(2*pi*q/M)-1`.

Then the resulting channel matrix `V` satisfies

`rank(V)=p`.

Thus the channel-space rank is exactly the number of active reflection orbits. The result is a structural rank statement; it does not make the fixed-unit compression number `K_tau` universal.

## 2. Exact shedding field

Write `alpha=pi/M` and use centered representatives `t=-k,...,k`. Since

`cos(2*pi*k*t/M)=cos((pi-alpha)t)=(-1)^t cos(alpha t)`,

we have

`X_t=1+A(-1)^t cos(alpha t)`.

For odd `|t|`, `X_t` is the local minimum and therefore `j_t=0`. At the origin,

`j_0=A(1+cos alpha)`.

For even `|t|>0`, monotonicity of cosine on the centered half-ring gives

`j_t=A[cos(|t| alpha)+cos((|t|-1)alpha)]`.

Hence `j` is real and reflection-even.

## 3. Fourier coefficients

Let `L=floor((M-1)/4)`. Reflection symmetry gives

`jhat_r = (1/M)[j_0 + 2 sum_{u=1}^L j_{2u} cos(4*pi*r*u/M)]`.

Finite trigonometric summation yields the residue-class formulas below.

### 3.1. M = 4L+3

For `0 <= r < k`,

`jhat_r = [2 A cos(alpha/2)/M] * B_r`,

where

`B_r = - sin(2 alpha)[(-1)^r cos(r alpha)+sin(alpha/2)] / [2 sin((2r-1)alpha) sin((2r+1)alpha)]`.

The denominator is nonzero for every integer `0<=r<k`. If `r` is even, the bracket is positive. If `r` is odd, then

`r alpha <= (k-1)alpha = pi/2 - 3 alpha/2`,

so

`cos(r alpha) >= sin(3 alpha/2) > sin(alpha/2)`.

Thus the bracket is strictly negative. Therefore

`jhat_r != 0` for every `0<=r<k`.

### 3.2. M = 4L+1

Here `k=2L`, and

`jhat_r = [2 A cos(alpha/2)/M] * B_r`,

with

`B_r = - sin(alpha)[(-1)^r cos(r alpha)cos(2r alpha)+cos(alpha)sin(alpha/2)] / [sin((2r-1)alpha) sin((2r+1)alpha)]`.

Again the denominator is nonzero for `0<=r<k`. A zero would require

`|cos(r alpha)cos(2r alpha)| = cos(alpha)sin(alpha/2)`.

Set `c=cos(alpha)sin(alpha/2)`.

For `0<=r<=L-1`, the function `f(x)=cos x cos 2x` is strictly decreasing on `[0,pi/4)`. Hence

`f(r alpha) >= f((L-1)alpha)`

`= cos(pi/4-5alpha/4) sin(5alpha/2)`.

Because `M>=9`, `alpha<=pi/9`. Therefore

`cos(pi/4-5alpha/4)>1/sqrt(2)`,

`sin(5alpha/2) >= 5alpha/pi`,

while `c < alpha/2`. Since `5/(pi sqrt(2)) > 1/2`, this gives `f(r alpha)>c`.

At `r=L`,

`|cos(L alpha)cos(2L alpha)| = cos(L alpha)sin(alpha/2)`.

Since `L alpha=pi/4-alpha/4>alpha`, we have `cos(L alpha)<cos alpha`, so the quantity is strictly less than `c`.

For `L+1<=r<=2L-1`, put `s=2L-r`, so `1<=s<=L-1`, and define `t=(s+1/2)alpha`. Then

`|cos(r alpha)cos(2r alpha)| = h(t) = sin t cos 2t`,

with

`3alpha/2 <= t <= pi/4-3alpha/4`.

Now

`h'(t)=cos t [1-6 sin^2 t]`,

so `h` has at most one critical point in this interval, and that point is a maximum. The minimum therefore occurs at an endpoint.

At the lower endpoint,

`h(3alpha/2)=sin(3alpha/2)cos(3alpha)`.

Using `sin(3alpha/2)/sin(alpha/2)=1+2cos alpha` and `cos(3alpha)>=1/2`,

`h(3alpha/2)/c >= (1+2cos alpha)/(2cos alpha) > 1`.

At the upper endpoint,

`h(pi/4-3alpha/4)=sin(pi/4-3alpha/4)sin(3alpha/2)`.

Since `alpha<=pi/9`, the first sine is at least `1/2`, and the same ratio identity gives

`h(pi/4-3alpha/4)/c >= (1+2cos alpha)/(2cos alpha) > 1`.

Thus `h(t)>c` throughout this discrete range. Equality is impossible in every case, and therefore

`jhat_r != 0` for every `0<=r<k`.

Combining both residue classes proves the non-vanishing lemma for every odd `M>=9`.

## 4. Rank proof before the stencil

Because `j` is real and reflection-even, the conjugate-balanced pre-stencil channels have the spatial form

`w_0(i)=jhat_0 m_i`,

and, for `r>=1`,

`w_r(i)=2 jhat_r m_i cos(2*pi*r*i/M)`.

There are `k+1` reflection orbits on an odd ring. Since at least one orbit is inactive, `p<=k`. Therefore the first `p` channel scales `jhat_0,...,jhat_{p-1}` are nonzero by Section 3.

Choose one representative `i_s` from each active reflection orbit and put

`x_s=cos(2*pi*i_s/M)`.

The `x_s` are distinct. After removing nonzero row and column scale factors, the `p x p` evaluation matrix of the first `p` channels is

`C_{rs}=T_r(x_s)`, `0<=r,s<=p-1`,

where `T_r` is the Chebyshev polynomial of degree `r`. Its determinant is a nonzero constant multiple of the Vandermonde product

`prod_{0<=i<j<p}(x_j-x_i)`.

Hence the first `p` pre-stencil channels are linearly independent. Reflection symmetry also bounds the active masked space by dimension `p`, so

`rank(W)=p`.

## 5. The stencil preserves rank

The Fourier multiplier

`s_q=cos(2*pi*q/M)-1`

vanishes only at `q=0`. Therefore the kernel of the corresponding spatial circulant stencil consists exactly of constant vectors.

Every vector in `span(W)` vanishes on every inactive site because every channel contains the mask factor `m_i`. Since at least one inactive site exists, the only constant vector in `span(W)` is the zero vector. Thus

`ker(S) intersect span(W) = {0}`.

The stencil is injective on the pre-stencil channel span, and consequently

`rank(V)=rank(SW)=rank(W)=p`.

This completes the proof.

## 6. Locked benchmark and neighboring rings

For the locked `M=99`, `A=0.50`, `theta=0.08` benchmark, the mask has 41 active reflection orbits, so the theorem gives

`rank(V)=41`.

For the same `A,theta` construction, the tested neighboring systems have

- `M=101`: 42 active reflection orbits and rank 42.
- `M=127`: 52 active reflection orbits and rank 52.

Exact cyclotomic remainder checks independently confirm non-vanishing of all required coefficients for these three rings.

2. compares the simplified analytic Fourier formulas with direct FFT coefficients over every odd `M=9,...,2001`;

The finite computational sweep is corroboration only. The family result is established by the analytic argument above.

## 8. Claim firewall

This theorem concerns the rank of a single-step phenomenological cyclic redistribution operator. It does not establish a microscopic physical law, a universal compression dimension, a universal value of `K_tau`, a multi-step dynamical theorem, or a result about the separate Gate 0 entropy-to-horizon question.
